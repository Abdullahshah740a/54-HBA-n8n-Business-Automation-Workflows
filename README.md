## Functionalities

- Membership revenue reconciliation, paid-share tracking and conversion reporting.
- CRM, outreach-event, appointment and department-task synchronization.
- Executive KPIs, weekly sales rollups, blog publishing analytics and YouTube reporting.
- Authenticated prospect intake, draft review, staging approval and controlled campaign release.
- Email reply/bounce monitoring, exclusion checks, provider outcome ingestion and recovery.
- AI research, scoring and copy tests with checkpoints, budget limits and no-send boundaries.

## Workflow

1. Select a project from the directory and read its guide, especially its limitations and dependencies.
2. Import the selected JSON into your n8n instance. Choose one alternate version when several are supplied.
3. Reconnect credentials and replace `EXAMPLE_*` identifiers, example URLs and synthetic contacts.
4. Create the required tables/sheets and rebind sub-workflow calls to your imported workflow IDs.
5. Review triggers, historical dates, prompts, approval gates and budgets. Use sample data to verify the complete path.
6. Activate only after configuration and testing; preserve all approval, no-send, ownership and spending controls.

## Tools

Depending on the selected project: n8n, JavaScript, Airtable, Google Sheets, GoHighLevel, Stripe, Asana, WordPress, Google Analytics 4, YouTube Data API, Instantly, OpenAI, Perplexity and Meridian/Supabase. The individual guides identify the tools actually used by each workflow.

## Repository structure

- `workflows/` — descriptive filenames for every supplied workflow version.
- `docs/` — individual functionality, workflow, tools, setup and limitation guides.
- `project-index.json` — machine-readable project-to-file mapping.
- `CONFIGURATION.md` — shared deployment checklist.

## Scope and validation

This repository contains the remaining n8n projects from the portfolio. Ten projects were already published separately; their repositories are retained. The Brand Blueprint and LinkedIn Profile Builder GHL projects await complete workflow exports and agent configuration, so they are not represented here as complete implementations.

All JSON files are parsed, workflow node counts and connection references are checked, and JavaScript Code nodes receive syntax checks without executing them. Provider access, live business outcomes and production readiness have not been verified. Credentials, cached execution data and pinned contact data were removed from these public copies. Resource placeholders and historical proof fixtures require configuration or regeneration.
